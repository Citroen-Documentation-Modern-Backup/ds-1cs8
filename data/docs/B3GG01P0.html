B3GG01P0Dépose - repose : bloc hydraulique
ANTI-BLOCAGE ROUE
1. Dépose
Vidange du circuit de freinage (voir opération correspondante).
Déposer :
  • La batterie
  • Le filtre à air
Figure : b3gp005c
Déposer :
  • Le support de batterie
  • Les 2 tubes (1)
  • Les 3 écrous (2)
IMPERATIF : Obturer les orifices du bloc hydraulique pour éviter toute introduction de corps étranger.
Désengager le porte-fusible ( 3) de son logement.
Figure : b3gp006c
Dégager le bloc hydraulique ( 4) de son support.
Déposer :
  • Le connecteur (5)
  • Les 4 tubes (6)
  • Le bloc hydraulique (4)
2. Repose
Présenter le bloc hydraulique (4).
Reposer les 4 tubes (6).
Reposer le bloc hydraulique ( 4) sur son support.
Reposer :
  • Les 2 tubes (1)
  • Les 3 écrous (2)
  • Le connecteur (5)
  • Le support de batterie
  • Le filtre à air
  • La batterie
Effectuer le remplissage et la purge du circuit de freinage (voir opération correspondante).
