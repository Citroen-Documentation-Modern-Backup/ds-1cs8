IMPERATIF : Toutes les surfaces décapées doivent être protégées par le procédé de rezingage électrolytique homologué : Référence C8.

Dépose - repose :
  • Les roues arrière
  • Le pare-chocs arrière
  • Les feux arrière
  • Le snappon
  • La gâche de volet arrière
  • Le tapis de coffre
  • L’ensemble coffre de batterie et son alimentation
Dégager les faisceaux.
2. Identification pièce de rechange
Figure : c4bp11uc
Panneau arrière assemblé .

4. Dégrafage
Figure : c4bp11vc
Dégrafer les lignes de points et les points à l’aide d’une fraise de Ø= 8 mm.
Figure : c4bp11wc

Déposer le panneau arrière assemblé.
