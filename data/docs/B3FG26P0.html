B3FG26P0Dépose - repose : Étriers de frein avant (disques ventilés)
1. Dépose
1.1. Étrier TEVES
Déposer les roues.
Figure : b3fp09vc
Débloquer le flexible de frein ( 4) de l’étrier (5).
Déposer :
  • Le ressort antibruit ( 1)
  • Les 2 capuchons (2)
  • Les 2 vis colonnettes (3)
Dégager l’étrier de frein ( 5) du support (6).
Déposer les plaquettes de frein .
Dévisser le flexible de frein ( 4), obturer celui-ci.
Déposer l’étrier de frein (5).
1.2. Étrier LUCAS
Déposer les roues.
Figure : b3fp09wc
Débloquer le flexible de frein ( 7) de l’étrier (8).
Déposer les vis (9).
Dévisser le flexible de frein ( 7), obturer celui-ci.
Déposer l’étrier de frein (8).
2. Repose
IMPERATIF : Les vis ( 3 ; 9) sont autofreinées et doivent être remplacées et remontées avec du (E3) à chaque remontage.
Procéder dans l’ordre inverse des opérations de dépose.
Serrage :
  • Vis (3) à 8,5 m.daN
  • Vis (9) à 8,5 m.daN
Purger le circuit de freinage (voir opération correspondante).
