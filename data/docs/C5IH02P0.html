C5IH02P0Remplacement : Patins de guidage
TOIT OUVRANT CDE MANUELLE
1. Dépose
Déposer :
  • La garniture de pavillon
  • Le toit ouvrant
  • Le panneau mobile
NOTA : Il est recommandé de changer les patins de guidage côté par côté.
Figure : c5ip02bc
Déposer :
  • Le boîtier manivelle ( 1)
  • Le mécanisme à câbles (2)
  • Les bras mobiles (3) (à l’avant)
Figure : c5ip02cc
Déposer :
  • La butée caoutchouc ( 4)
  • Le chariot (5)
Figure : c5ip02dc
Remplacer les patins de guidage ( 6).
2. Repose
Figure : c5ip02ec
Engager le chariot ( 5) respectivement dans la coulisse (7) et dans le câble (8), à l’aide des guides "a" et "b".
Remettre la butée caoutchouc ( 4).
Engager le bras mobile ( 3) (à l’avant).
Effectuer la même opération de l’autre côté.
IMPERATIF : Avant de continuer la repose, contrôler que les guides des chariots et des bras mobiles sont bien dans leurs coulisses.
Figure : c5ip02fc
Reposer le mécanisme à câbles ( 2) sur son cadre et préserrer les fixations (9).
Mettre les chariots ( 5) en ouverture maximum, sur les butées arrière.
Reposer le boîtier manivelle ( 1).
IMPERATIF : Après la repose du boîtier manivelle ( 1), contrôler que les chariots (5) sont bien restés en butée.
Serrer l’ensemble des fixations ( 9) et les fixations du boîtier manivelle (1).
Mettre le mécanisme à câbles ( 2) en position fermée.
Figure : c5ip02gc
IMPERATIF : Vérifier que les bras mobiles ( 3) sont bien restés dans leurs coulisses.
Reposer le panneau mobile.
Préserrer les fixations du panneau mobile.
Nettoyer la surface d’appui du toit ouvrant sur le pavillon.
Figure : c5ip02hc
Contrôler l’état des éléments suivants :
  • Joint d’étanchéité (10)
  • Mousses antibruit (11)
Figure : c5ip02jc
Reposer le toit ouvrant.
Contrôler le centrage à l’aide des tétons " c" et du positionnement de l’agrafe (12).
Figure : c5ip02kc
Préserrer les fixations (13) (respecter l’ordre indiqué).
Serrer les fixations ( 13) à 0,5 m.daN.
Procéder dans l’ordre inverse des opérations de dépose.
