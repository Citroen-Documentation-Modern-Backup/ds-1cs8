B3DG0CP0Dépose - repose : Liaisons élastiques de traverse arrière
1. Outillage préconisé
Figure : e5-p13jc
[ 1] grain extracteur 4502-T.D1.
[ 2] appui d’extracteur 4502-T.D2.
[ 3] appui de montage 4502-T.D3.
[ 4] embout de montage 4502-T.D4.
[ 5] vis, écrou et rondelle 4502-T.D5.
2. Dépose
Déposer le train arrière (voir opération correspondante).
Figure : b3dp02xc
Monter les outils [ 1] [2] et [5] sur le support élastique.
Extraire le support élastique , En vissant l’écrou.
Répéter l’opération sur les 3 autres supports élastiques.
3. Repose
ATTENTION : Avant montage : Orienter les supports élastiques.
Figure : b3dp02yc
Les alvéoles doivent être inclinées de 18 à 21° (angle A).
Figure : b3dp02zc
Monter les outils [ 3] [4] et [5] sur le support élastique.
Serrer l’ensemble jusqu’en butée de l’épaulement de l’outil sur le bras de traverse arrière.
Répéter l’opération sur les 3 autres supports élastiques.
